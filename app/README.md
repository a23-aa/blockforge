# BlockForge

Лаунчер Minecraft для Windows с современным тёмным интерфейсом.

## Как запустить (самый простой способ)

1. Установи **Node.js LTS** — https://nodejs.org/ (один раз).
2. Распакуй папку и дважды кликни **`start.bat`**.
   При первом запуске он сам скачает компоненты (~2–3 минуты), дальше открывается мгновенно.

## Как получить обычный установщик / .exe

Дважды кликни **`build.bat`**. В папке `dist` появятся:
- установщик `BlockForge Setup x.x.x.exe`
- портативная версия (один .exe, не требует установки)

Если сборка падает с ошибкой про symbolic link — включи «Режим разработчика» в Windows
(Параметры → Конфиденциальность и безопасность → Для разработчиков) или запусти `build.bat` от администратора.

## Что умеет

- Любые версии Minecraft: релизы, снапшоты, old_beta / old_alpha (манифест Mojang).
- Загрузчики: **Fabric, Quilt, Forge, NeoForge** (Forge/NeoForge ставятся официальным установщиком).
- Автоматическая загрузка нужной **Java** (Mojang-рантайм: Java 8 / 17 / 21 — под каждую версию игры).
- Моды, ресурспаки и шейдеры из **Modrinth** с автоустановкой обязательных зависимостей;
  список установленных, включение/выключение, удаление.
- Отдельная папка, память и JVM-аргументы для каждой сборки.
- Аккаунты: офлайн и Microsoft (лицензия). Токены шифруются средствами Windows.

## Вход через Microsoft

Нужен свой **Client ID** (один раз, бесплатно):

1. https://portal.azure.com → *Microsoft Entra ID* → *App registrations* → *New registration*.
2. Supported account types: **Personal Microsoft accounts only** (или «any … and personal»).
3. После создания: *Authentication* → включи **Allow public client flows** → Save.
4. Скопируй **Application (client) ID** в «Настройки» лаунчера.
5. Mojang требует одобрения новых приложений для Minecraft API:
   заявка на https://aka.ms/AppRegInfo . До одобрения вход может отвечать ошибкой
   (`Invalid app registration`) — тогда пользуйся офлайн-аккаунтом.

## Где лежат данные

`%APPDATA%\blockforge\minecraft` — версии, библиотеки, Java и папки сборок (`instances\`).
Кнопка «Открыть папку данных» в настройках.

## Структура проекта

- `main.js`, `preload.js` — Electron (окно и связь с интерфейсом)
- `core/` — логика: `minecraft.js` (версии, библиотеки, ассеты, Java, аргументы), `loaders.js`, `mods.js`, `auth.js`, `launch.js`
- `renderer/` — интерфейс (HTML/CSS/JS)

## Что не реализовано / ограничения

- Моды из CurseForge (нужен API-ключ) — пока только Modrinth.
- Импорт модпаков (.mrpack / CurseForge zip) — не реализован.
- OptiFine не ставится автоматически (используй Sodium/Iris на Fabric).
- Forge старше 1.12 и экзотические сочетания версий зависят от официального установщика Forge.


## Что нового в финальной версии
- Мультяшный дизайн, карточки-острова с деревьями (рисуются в самом лаунчере).
- Редактор скинов (вкладка «Скины»): рисование, 3D-превью, импорт/экспорт PNG, загрузка по нику, применение к Microsoft-аккаунту.
- Карточка «Мой сервер» на главной: Настройки -> название и адрес сервера.
- Моды: в сборке «Vanilla» моды не работают - выбери Fabric (кнопка в разделе «Моды»). Есть ручное добавление файлов и обновление модов.
- Данные лежат в %APPDATA%\blockforge.

## Скорость
- Окно показывается сразу, картинки-острова дорисовываются по одной.
- Повторный запуск игры не перепроверяет тысячи файлов (метка .ready), Java и файлы игры готовятся параллельно.
- Быстрые настройки сборщика мусора Java. Если в сборке заданы свои JVM-аргументы, они используются вместо них.


## Новое: скины, друзья, переводчик, свой сервер
- **Готовые скины** (вкладка «Скины»): 12 скинов, кнопка «Надеть». У Microsoft-аккаунта скин сразу уходит в игру.
- **Лаунчер прячется**, когда открылось окно Minecraft, и возвращается после закрытия игры (Настройки -> «После запуска игры»).
- **Переводчик** (RU/EN/DE/FR/ES/IT/PT/PL/UK/TR/ZH/JA/KO), работает через MyMemory.
- **Друзья**: регистрация (ник + пароль, проверка сложности), личный 8-значный ID, добавление по ID, заявки, статус «в сети / играет на…».
  Для этого нужен сервер аккаунтов, он лежит в папке `server-api` (нужен Node.js 18+).
  Локально: запусти `server-api\start-api.bat`, адрес в Настройках оставь `http://localhost:3000`.
  Для всех людей: размести папку `server-api` на любом хостинге с Node.js (VPS, Render, Railway), поставь HTTPS и впиши публичный адрес в `core/store.js` (apiUrl) перед сборкой.
  Тест сервера: `node server-api\test.js`.
- **Свой сервер** (вкладка «Серверы»): лаунчер скачивает Paper, запускает его, online-mode выключен. Из интернета заходят через проброс порта 25565 или туннель (playit.gg).

## Меню стало короче
Слева 6 пунктов: Главная, Играть, Моды, Скины, Друзья, Настройки. Остальное внутри вкладок:
- Играть: Играть / Мои сборки / Серверы
- Друзья: Друзья / Чаты (общий чат и личные, кнопка «Позвать играть» с приглашением на твой сервер)
- Настройки: Основное / Переводчик / Свой сервер (режимы: выживание, анархия, мини-игры; плагины BedWars, SkyWars и другие ставятся из Modrinth)


## Обновление: язык, скины, журнал
- **Язык интерфейса**: кнопка с глобусом в правом верхнем углу (RU, EN, UK, DE, ES, FR, PT, PL, TR, ZH). Весь текст лаунчера переводится, кроме названия BlockForge, ников и названий сборок/серверов. Русский и английский переведены полностью, остальные языки — автопереводом (MyMemory), переводы запоминаются.
- **Скин для офлайн-аккаунта**: лаунчер сам кладёт ресурспак BlockForgeSkin.zip в папку сборки и включает его, поэтому свой скин виден тебе в игре. Другие игроки видят его только при входе через Microsoft.
- **Журнал убран**: на странице «Играть» теперь карточки со сведениями; подробности ошибки открываются кнопкой при сбое запуска.
- **Друзья**: если адрес сервера аккаунтов указывает на этот же компьютер (по умолчанию http://127.0.0.1:3000), лаунчер сам поднимает встроенный сервер, ничего запускать вручную не нужно. Для настоящих игроков нужен общий сервер из папки server-api.

## Регистрация и загрузка скинов
- При первом запуске BlockForge предлагает создать аккаунт (ник + пароль, проверка надёжности), войти, зайти через Microsoft или играть без аккаунта. Друзья и чаты доступны только с аккаунтом BlockForge или Microsoft.
- На вкладке «Скины» можно перетащить скачанный PNG (64×64 или 64×32): скин сразу надевается и сохраняется в библиотеку.

## Премиум ($1 в месяц) и оплата
- **Бесплатно:** запуск Vanilla-версий Minecraft, одна сборка, вход через Microsoft или офлайн, автоскачивание Java.
- **Премиум:** моды и загрузчики, скины, друзья и чаты, свой сервер, много сборок, язык интерфейса. Что платно, а что бесплатно, задаётся списком `PAID` и `GATES` в `core/premium.js`.
- Премиум привязан к аккаунту BlockForge. Друзья и чаты дополнительно проверяются на сервере аккаунтов, остальное проверяет лаунчер.
- **Как принимать оплату без своего платёжного кода:** продаёшь подписку на Boosty (или в любом сервисе), после оплаты создаёшь код и отправляешь покупателю. Покупатель вводит его в Настройки, Премиум.
  1. На сервере аккаунтов задай переменную `ADMIN_KEY` (любая длинная строка, от 12 символов).
  2. Создать коды: `node server-api/make-codes.js http://адрес:3000 ТВОЙ_КЛЮЧ codes 30 5` (5 кодов на 30 дней).
  3. Выдать Премиум напрямую: `node server-api/make-codes.js http://адрес:3000 ТВОЙ_КЛЮЧ grant Ник 30`.
- Чтобы кнопка «Купить Премиум» открывала твою страницу оплаты, в `config.json` лаунчера (папка данных) добавь `"buyUrl": "https://..."`.
- Лаунчер можно взломать на своём компьютере, поэтому по-настоящему защищены только друзья и чаты (проверка на сервере).

## Java
Настройки → Java: автоматический выбор, список найденных Java, выбор своего `java.exe`, скачивание Java 8, 17 или 21.
Лаунчер проверяет, что выбранная Java подходит версии игры, и объясняет ошибку.

## Платформы
Сейчас лаунчер работает только на Windows. Версия для Mac в разработке.

## Telegram-бот для продажи Премиума (Telegram Stars)
Файл `server-api/bot.js` (запуск: `server-api/start-bot.bat`, на хостинге уже входит в папку `deploy`).
Как это работает для покупателя: пишет боту, присылает свой ID из лаунчера (8 цифр, виден слева внизу), платит Telegram Stars, и Премиум включается в аккаунте сам. Код вводить не нужно.
- **Подписка с автопродлением** (раз в 30 дней, отменяется в Telegram) и **разовая оплата** на 30 дней.
- **Перевод на карту** по желанию: реквизиты в `PAY_TEXT`, ты подтверждаешь кнопкой.
- Команды владельца: `/who ID` (статус), `/grant ID дни` (выдать вручную), `/gen дни сколько` (коды).
- Платежи записываются в `bot-payments.log`, повторный платёж с тем же номером не обрабатывается.
Создание бота: **@BotFather** → `/newbot` → токен; свой Telegram ID можно узнать командой `/id` у бота. Токен, ID, адрес сервера и админ-ключ впиши в `start-bot.bat`.
